# Demo 资源分类与操作说明

## 1. 目录用途

`Demo/` 用于集中存放演示相关素材，避免与源码、脚本和调试产物混放。

当前分类如下：

- `Demo/Pic/`：图片、压缩包、实物照片
- `Demo/操作说明.md`：演示资源说明与补充规则

## 2. 当前资源现状

`Demo/Pic/` 当前已归档以下类型资源：

- 实物图片目录
- 原始图片文件
- 图片压缩包

当前仓库内尚未单独整理出视频目录；后续若补充演示视频，建议新增：

- `Demo/Video/`：演示视频
- `Demo/Guide/`：面向演示的操作步骤、串口连接说明或录屏脚本说明

## 3. 使用约定

1. 演示照片、录屏截图、对外展示素材统一放入 `Demo/`。
2. 调试过程中临时生成的截图不要放入 `Demo/`，统一放到 `Project/Debug/debug_snapshots/`。
3. 图片转换、素材预处理脚本不要放入 `Demo/`，统一放到 `Project/Script/media_tools/`。
4. 若后续新增操作手册、演示步骤或视频说明，优先放在 `Demo/` 下，而不是散落到源码目录。

## 4. 相关路径

- 图片资源：`Demo/Pic/`
- 调试截图：`Project/Debug/debug_snapshots/`
- 素材处理脚本：`Project/Script/media_tools/led_image_converter_gui.py`

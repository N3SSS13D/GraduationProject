# PWM 通道错乱问题复盘（中文）

## 1. 现象

- 在双通道 PWM + DMA 并行输出时，部分通道组会偶发数据错乱。
- 典型表现是某一段发送过程中 CH1 数据跑到 CH2，或两通道出现短时错位。

## 2. 根因分析

1. 发送长度未严格按 CH1/CH2 成对对齐。
2. DMA 源缓冲起始地址未固定对齐，导致特定边界下行为不稳定。
3. 传输尾部边界对硬件时序抖动敏感。
4. 异常场景缺少超时恢复，可能把错误状态带到下一帧。

## 3. 已落地的修复策略

1. 强制偶数字节长度发送：`alignedNum = num & ~1`。
2. 固定 DMA 源缓冲地址对齐：使用原始缓冲 + 对齐指针。
3. 发送尾部追加一对 CH1/CH2 零值保护对。
4. 严格 DMA 启动顺序：复位状态 -> 配置地址/长度 -> 置忙 -> 使能并触发。
5. 增加等待超时与恢复：超时后强制复位 DMA 相关寄存器并清 busy。
6. 固定通道映射规则：偶数行固定 CH1，奇数行固定 CH2。

## 4. 本次模块化重构结果

- 已将图像缓冲与 PWM+DMA 发送能力沉淀到 `Sources/drv/ws2812_drv.c`。
- `Sources/app/test.c` 仅保留测试调度与固定图案构建，通过驱动接口执行发送。
- DMA 中断统一转发到 `WS2812DRV_OnDmaIsr`，避免状态分散。

## 5. 后续开发建议

1. 任何双通道发送都必须保证长度成对与地址对齐。
2. 禁止绕开统一发送接口直接操作 DMA 寄存器。
3. 保留尾部保护对与超时恢复逻辑，不要在优化中删减。
4. 若新增图案或分辨率，仅修改图像缓冲和编码层，不要破坏发送链路。

## 6. 共线微亮问题（已确认方案）

### 6.1 现象

- 点亮某一行时，与其共用信号路径的行会出现微弱点亮。

### 6.2 已确认的硬件解决办法

- 在电源侧增加放电电阻后，残余电荷导致的弱亮现象可有效消除。
- 该硬件措施作为当前问题的一线解决方案。

### 6.3 软件侧配合策略

1. 行选更新采用固定顺序：
	- 先执行全关断，
	- 延时一小段时间，
	- 再执行新行选通。
2. DMA 完成中断不再立即全关断，避免额外占空损失。

### 6.4 结论

- 亮度与抗串扰之间存在折中。
- 实际工程中优先使用硬件放电电阻解决根因，软件策略用于稳定时序与降低边界风险。

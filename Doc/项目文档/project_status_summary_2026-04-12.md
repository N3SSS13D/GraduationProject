# 项目现状总结与下一阶段计划（2026-04-12）

## 1. 仓库定位

`GraduationProject` 当前由三条主线组成：

1. `STC51/Project/ws2812_driver/`
	 - 基于 STC AI8051U 的 WS2812 复用扫描显示工程。
	 - 当前重点是稳定 PWM + DMA、74HC595 行选、PMOS 高侧切换和 USB 调试链路。
2. `External/xiaozhi-esp32/`
	 - 引入的小智 AI 参考快照。
	 - 当前重点是复用其语音交互、MCP、板级抽象和 `GP_Port/` 扩展资产。
3. `Doc/项目文档/` 与 `.github/prompts/`
	 - 用于沉淀当前实现状态、开发约束、分阶段任务和后续集成计划。

## 2. 当前项目结构

### 2.1 STC51 显示主线

- `Sources/app/`
	- 负责测试调度、模式切换、扫描触发等应用层流程。
- `Sources/mid/`
	- 负责渲染、动画步进、按键控制等中间层逻辑。
- `Sources/drv/`
	- 负责 `ws2812_drv`、`hc595_drv` 等显示与行选驱动。
- `Sources/inc/`
	- 负责头文件、配置和共享声明。
- `Sources/*.c`、`Sources/lib/`
	- 负责 MCU 外设初始化、中断、USB、定时器和厂家库支撑代码。

### 2.2 小智 AI 参考主线

- `main/application.cc`
	- 小智主应用调度入口，负责状态机、音频、网络、显示与 MCP 工具协调。
- `main/boards/`
	- 板级硬件抽象入口，当前 GP_Port 方案锚定在 `lichuang-dev` 目标板。
- `main/led/`
	- LED 抽象层，适合作为矩阵状态映射的最小接入边界。
- `GP_Port/`
	- 本仓库针对毕业设计新增的协议、驱动骨架、AI8051U 接口设计、联调脚本与阶段 prompt。

## 3. 已实现功能总结

### 3.1 STC51 / WS2812 侧

- 已完成 PWM + DMA 双通道驱动路径整理，关键发送能力集中到 `ws2812_drv`。
- 已完成 74HC595 + PMOS 行扫描链路，支持稳定行选与复位尾波控制。
- 已完成 Timer0 one-shot 扫描节拍调度，减少关键路径中的软件延时。
- 已保留并优化两类扫描/发送方案：`normal_pair` 与 `legacy_shift`。
- 已实现 USB 调试命令：颜色、换行间隔、图案索引、渲染模式切换。
- 已支持 16x64 / 16x8 两种有效列模式，以及运行时 DMA 长度重建。
- 已沉淀当前实现说明与问题复盘文档，便于后续继续收敛驱动边界。

### 3.2 XiaoZhi / GP_Port 侧

- 已引入 `xiaozhi-esp32` 快照，保留语音交互、MCP、板级抽象和多协议通信参考。
- 已补充共享协议头 `GP_Port/gp_led_matrix_protocol.h`。
- 已补充并接通 ESP32 侧矩阵驱动 `GP_Port/gp_led_matrix_esp32.h/.cc`。
- 已补充并落地 AI8051U 接口层 `gp_led_matrix_ai8051u.h/.c`、动作执行层 `gp_led_action.h/.c`。
- 已补充 AI8051U 接口设计、协议说明、项目总览和分阶段 prompt。
- 已完成 MCP 调试圆点工具、计算器工具和桥接端点测试脚本。
- 已验证官方 MCP 端点握手模式为“桥接端主动 initialize，本地作为 server 响应”。
- 已实现语音颜色与预设识别，并可直接映射为矩阵动作对象。
- 已实现 `SetAction`、`Frame*`、`ScrollGlyph*`、`Status/Error` 回包的本地 I2C 闭环。
- 已实现 AI8051U USB I2C 日志细分，可区分 `payload_stop`、`restart_flush`、`empty_stop` 与真实协议执行包。
- 已实现 ESP32 侧回包校验、链路状态面板和最近命令摘要显示。
- 已改为“仅在显式图像更新时通信”，待机/聆听状态不会再自动覆盖上一幅矩阵图像。
- 已将原测试动画整理为可调用预设：`diamond`、`cross`、`python_demo`、`scroll_subtitle`。

## 5. 下一阶段目标

下一阶段主目标是构建以下闭环：

`小智 AI 语音结果 -> ESP32 侧动作映射 -> I2C 自定义协议 -> AI8051U 接收解析 -> WS2812 显示执行`

期望能力包括：

- 语音识别颜色、亮度、动画、显示文本等意图。
- ESP32 将高层意图稳定映射成协议包，而不是直接耦合 STC 细节。
- AI8051U 负责接收协议包、维护显示上下文并执行矩阵刷新。
- WS2812 显示链路保持确定性，避免被 AI 消息抖动直接扰动。

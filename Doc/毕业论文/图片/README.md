# 毕业论文图片素材索引

本目录用于集中保存论文写作、答辩展示和阶段性验证中使用的图片素材。

当前整理原则如下：

1. 保留已有原始文件名，避免打断外部文档或论文模板中的现有引用。
2. 通过本索引文件按用途分类，降低后续插图选取和图注编写成本。
3. 流程图、硬件图、实物图和实验结果图统一收口到 `Doc/毕业论文/图片/`，便于随论文一并版本化管理。

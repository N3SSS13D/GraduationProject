- **配图**: 章节流程图

### 第3页：研究背景与意义 (60秒)
- LED显示屏的广泛应用与智能化趋势
- 人工智能赋能嵌入式设备的时代背景
- 蓝牙技术在短距离低功耗通信中的优势
- 语音交互作为自然用户界面的需求
- **配图**: LED+蓝牙+语音三元素拼贴

### 第4页：研究目标 (45秒)
- 设计蓝牙驱动的16×16 WS2812 LED矩阵显示系统
- 实现ESP32-S3语音智能交互控制
- 构建轻量级二进制蓝牙通信协议
- 开发基于MCP的LLM智能绘图系统
- **配图**: 系统预期效果示意图

### 第5页：系统总体架构 ★重点页 (90秒)
- 4层架构：主机生成层 → 调度控制层 → 协议层 → 驱动执行层
- 主数据链：Script → AI-side → Bluetooth → LED-side → Display
- 双控制路径：本地触摸/语音关键词 + 远程MCP自由绘图
- **配图**: 全系统框图和标注数据流方向

### 第6页：硬件组成概览 (60秒)
- AI8051U主控 + ESP32-S3 AI处理器
- HC-05蓝牙模块 ×2（主从配对）
- 16×16 WS2812B LED矩阵
- 关键参数：PWM 691kHz, MCU 33.1776MHz, UART 460800bps
- **配图**: 标注的硬件实物照片

### 第7页：LED矩阵硬件设计 (60秒)
- 行扫描架构：8行对扫描，PWM+DMA自动波形输出
- 74HC595行选逻辑：3片级联驱动16行
- WS2812B时序要求与实现方案
- **配图**: 行扫描时序图 + PCB照片

### 第8页：蓝牙通信硬件 (30秒)
- HC-05主从配对方案
- UART传输参数：AT 38400bps, 数据 460800bps
- **配图**: 蓝牙连接拓扑图

### 第9页：LED驱动层（软件）★重点页 (90秒)
- WS2812B PWM+DMA自动波形生成方案
- 三级编码管线：RGB像素 → 行PWM编码 → 双行DMA缓冲
- 256×8查找表实时编码
- 双缓冲防撕裂机制
- **配图**: 编码管线图 + 示波器PWM波形截图

### 第10页：LED渲染层（软件）(60秒)
- 渲染管线：内容类型 → 坐标映射 → 颜色重映射 → 效果处理 → 亮度调节
- 效果系统：呼吸、渐变、滚动、淡入淡出、颜色循环、行显隐等
- 统一时间线动画调度
- 本地离线图案资源管理
- **配图**: 渲染流程图 + 多种效果实拍

### 第11页：LED通信层（软件）(45秒)
- UART2+DMA自动接收（192字节环形缓冲）
- 三态接收状态机：IDLE → HEADER → PAYLOAD → CRC
- 双CRC校验：header_crc8 + packet_crc16
- 魔数(0x47)字节流定界
- **配图**: 收包状态机流程图

### 第12页：AI端接口（软件）★重点页 (90秒)
- 双控制路径设计：
  - 路径A：本地触摸 + 语音关键词 → SetAction直发蓝牙（<20ms延迟）
  - 路径B：自由语音 + MCP工具 → 主机绘图 → 结果回传（0.5-3s）
- WebSocket实时结果投递 + HTTP回退
- 动画缓冲：最多32帧，自动重采样
- **配图**: 双路径控制流图

### 第13页：协议设计（软件）★重点页 (90秒)
- 紧凑二进制协议：6字节包头 + 负载 + CRC16
- 包格式字节布局详解
- 三种图像表示格式对比：RGB332(256B) / 紧凑位图(38B) / 分层位图(36B/层)
- 请求-回复事务模型与ACK匹配
- 创新点：双CRC（header CRC8+packet CRC16）提升抗噪能力
- **配图**: 封包字节布局图 + 格式对比表

### 第14页：协议命令体系 (45秒)
- 4类命令：参数/控制、整帧图像、动画、轻量图像
- 核心命令：SetAction(28B)、LayeredFrame(0x18)、AnimationStart/End
- **配图**: 命令树状分类图

### 第15页：绘图脚本与MCP（软件）★重点页 (90秒)
- MCP桥接架构：LLM ↔ MCP ↔ 桥接服务 ↔ ESP32 ↔ LED
- 4种绘图能力：直接位图、自然语言提示、Python绘图(AST白名单安全)、文字渲染
- AST白名单安全机制：只允许安全绘图函数
- 创新点：LLM通过标准化MCP协议控制LED显示
- **配图**: MCP架构图 + 工具列表截图

### 第16页：数据转换全链路演示 (60秒)
- 端到端实例："画一个红心" → LED像素点亮全过程
- 逐阶段数据格式变化展示
- 字节级数据追踪
- **配图**: 数据转换流程图（含各阶段实际数据）

### 第17页：关键技术难点 (60秒)
- 难点1：WS2812苛刻时序 → PWM+DMA自动波形生成解决
- 难点2：UART噪声干扰 → 双CRC校验解决
- 难点3：高效图像传输 → 分层位图格式（最高5倍压缩）
- 难点4：ESP32-S3内存压力 → 按需启动调试服务
- **配图**: 每个难点前后对比

### 第18页：单元测试 (45秒)
- LED驱动：PWM波形示波器测量、扫描时序验证
- 协议：CRC错误注入测试、边界条件测试
- 脚本：MCP工具参数验证、AST安全测试
- **配图**: 示波器截图 + 测试结果表

### 第19页：集成测试 (45秒)
- 语音端到端："显示一个红色爱心" → LED正确显示
- 蓝牙吞吐量：不同负载下的持续帧率测试
- 动画播放：32帧流畅度验证
- **配图**: 测试场景照片 + 吞吐量图表

### 第20页：可靠性验证 (30秒)
- 长时间运行：1小时连续蓝牙传输，0丢帧
- 抗干扰：双CRC保护，有意干扰下仍正常工作
- 断连恢复：蓝牙断连后自动重连
- **配图**: 可靠性统计表

### 第21页：创新点总结 ★重点页 (60秒)
1. 双CRC轻量级协议确保蓝牙传输可靠性
2. MCP集成实现自然语言控制LED绘图
3. 分层位图格式实现最高5倍传输压缩
4. PWM+DMA自动波形生成消除CPU时序开销
5. 统一显示配置文件架构解耦本地/远程渲染
- **配图**: 每个创新点配图标

### 第22页：实物展示 (60秒)
- 多种图案和颜色效果照片
- 语音交互演示说明
- MCP工具绘图示例

- **配图**: 矩阵多种显示内容照片拼贴 + 演示视频二维码
